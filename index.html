SET UP ทีมเซล

รายชื่อเซลแต่ละคนอยู่ทีมไหน ใช้ในหน้า "ทีมเซล" และ "Focus Sale" — ค่านี้ฝังอยู่ในระบบ ทุกคนเห็นเหมือนกัน

ทีมที่ใช้งาน

ทีมสีเหลือง = ทีมที่ดูแล แสดงเป็นตารางแยกในหน้า "ทีมเซล" และรวมอยู่ในแถว "รวมทุกทีม" · ทีมสีเทา (ไม่ได้ดูแล เช่น Team_Charlie) แสดงแยกท้ายหน้า ไม่นับรวม · "เซลล์ที่ลาออก" เป็นกลุ่มถาวร ไม่นับเป็นทีม · ถ้าต้องการเพิ่มทีม ย้ายทีม หรือมีเซลใหม่ ให้แจ้งผู้ดูแลแดชบอร์ดแก้ไฟล์แล้วอัปโหลดใหม่

รายชื่อเซล

ชื่อเซลLead ที่ดูแลทีม
รายชื่อมาจากคอลัมน์ "Sale ที่ดูแล" ในข้อมูล Lead สด + ชื่อเซลที่มีในยอดขาย · เซลคนใหม่ที่ยังไม่มีในระบบจะขึ้นเป็น "ยังไม่จัดทีม" (แถวสีแดง อยู่บนสุด) และแสดงเป็นกลุ่มแยกในหน้าทีมเซล จนกว่าจะเพิ่มชื่อลงในระบบ

ตรวจข้อมูล

รวมจุดที่ควรแก้ในชีท เพื่อให้ตัวเลขในแดชบอร์ดครบและถูกต้อง — แก้ในชีทแล้วกด "รีเฟรชข้อมูล" ตัวเลขจะอัปเดตทันที ไม่ต้องอัปโหลดไฟล์ใหม่

Inbound / Outbound / Event

การแบ่งว่าแต่ละคู่ Source × Channel เป็นลูกค้าที่ทักเข้ามาเอง (Inbound), ทีมเซลล์ติดต่อออกไป (Outbound) หรือมาจากงานอีเวนต์ (Event) — ใช้ในหน้าภาพรวม, Marketing, ทีมเซล, Focus Sale และสรุปตาม Source
